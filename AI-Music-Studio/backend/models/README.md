# Pretrained AI Models Directory

Demucs (`htdemucs` and `htdemucs_6s`) downloads open-source pretrained checkpoints automatically on first separation request into your PyTorch cache (or into `TORCH_HOME` if set to this directory).

Supported Demucs open-source models:
- `htdemucs` — 4-stem separation (vocals, drums, bass, other) & 2-stem vocal/instrumental separation.
- `htdemucs_6s` — 6-stem separation (vocals, drums, bass, piano, guitar, other).
